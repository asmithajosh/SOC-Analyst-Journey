## Topics Learned

### Network Visibility

Network visibility is the ability to observe traffic flowing through a network.

Benefits:

- Detect suspicious activity
- Monitor user behavior
- Investigate incidents
- Improve security posture

---

### Network Monitoring

Security teams monitor:

- Network traffic
- Logs
- Alerts
- Authentication events

Common monitoring tools:

- IDS
- IPS
- SIEM

---

### Firewall Logs

Firewall logs record:

- Source IP
- Destination IP
- Port numbers
- Allowed or blocked connections

Used for:

- Detecting scans
- Investigating attacks
- Tracking suspicious activity

---

### VPN Authentication Logs

VPN logs contain:

- Login attempts
- Successful logins
- Failed logins
- Assigned IP addresses

Useful for:

- Detecting brute-force attacks
- Identifying compromised accounts

---

### IDS Alerts

Intrusion Detection Systems generate alerts when suspicious activity is detected.

Examples:

- Port scans
- Malware traffic
- Command and Control communication
- Data exfiltration attempts

---

## Key Takeaway

Network security analysts rely heavily on logs to investigate attacks, identify malicious activity, and respond to incidents.
