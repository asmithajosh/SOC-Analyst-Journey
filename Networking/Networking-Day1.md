- DNS
- IP Address

## DNS

DNS converts domain names into IP addresses.

Example:

instagram.com → IP address

## IP Address

An IP address identifies a device on a network.

Example:

192.168.1.10

## Packets

Data travels across networks in small pieces called packets.

## HTTP vs HTTPS

HTTP:
- Unencrypted

HTTPS:
- Encrypted

HTTPS protects data while it travels across the internet.

## Why SOC Analysts Care

SOC Analysts monitor:

- DNS requests
- Suspicious IP addresses
- Network traffic
- HTTP and HTTPS activity
